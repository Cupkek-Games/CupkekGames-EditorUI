# CupkekGames EditorUI

Reusable editor widgets used by other CupkekGames packages' inspectors and tools. Extracted from `com.cupkekgames.core`.

## What's inside

**Editor** (`CupkekGames.EditorUI.Editor.asmdef`)
- `EditorColorPalette` (+ `.uss`) — shared editor color palette stylesheet
- `EditorImGuiDrawing` — IMGUI helpers
- `FoldoutListView`, `FoldoutSection`, `TypePickerField`, `EditorUIElements` — UI Toolkit widgets
- `EditorTabView`, `SearchableDropdown` — more UI Toolkit components
- `SpritePreviewUtility` — sprite preview rendering helpers

## Dependencies

None.
